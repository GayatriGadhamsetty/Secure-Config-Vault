You are an expert full-stack software engineer, UI/UX designer, database architect, and AI application developer.

Build a complete production-quality full-stack web application called:

"FreelanceMatch"

Tagline:
"Find the right person. Build the right project."

IMPORTANT:
Do not build a generic freelancer marketplace clone.
The core differentiator is AI-powered project compatibility, trust, safety, and two-way matching.

The application connects:
1. Clients who have projects
2. Freelancers who are looking for projects

The platform should help both sides find a suitable match based on:
- Skills
- Experience
- Portfolio relevance
- Budget
- Availability
- Deadline
- Project requirements
- Ratings and feedback
- Skill verification

The platform should also help prevent problems before and during a project.

2. SECURITY
==================================================

NEVER hardcode secrets.

Use environment variables:

SUPABASE_URL=YOUR_SUPABASE_URL

GEMINI_API_KEY=YOUR_GEMINI_API_KEY
JWT_SECRET=YOUR_JWT_SECRET

Never put real API keys in:
- React frontend
- source code
- GitHub
- README
- client-side JavaScript

Gemini API calls must happen only on the Express backend.

Validate:
- Request body
- Query parameters
- Route parameters
- Authentication data
- AI responses

Users must only be able to access their own private data.

Use secure password hashing with bcrypt.

Use JWT authentication for protected routes.
